# Changelog

## v0.1.1 — Stability Hardening

- Hardened SMC Order Block detection: default impulse threshold is now 1.0 ATR, exposed through the function API.
- Improved Order Block mitigation semantics: a retest/touch alone no longer invalidates a zone; mitigation requires a decisive close through the far edge.
- Removed deprecated timezone-naive `utcnow()` usage from ML model timestamps.
- Verified the complete automated test suite: 36/36 tests passing.
- Verified Python bytecode compilation for `src/`, `scripts/`, and `streamlit_app.py`.

> This release does not claim zero defects in every broker/environment. Live trading should remain disabled until broker credentials, symbol specifications, spread, contract size, and execution behavior are verified on the target MT5 installation.

## v0.4.0 — Phase 4 Advanced Intelligence & Execution

- Added a dedicated `src/phase4` package with deterministic production primitives for feature engineering, SMC structure, AI scoring, signal orchestration, adaptive exits, portfolio risk, execution controls, real-time state, validation, analytics, news impact and regime tracking.
- Added Phase 4 integration tests; all existing and new tests pass.
- Kept market-data policy real-data only: no synthetic market observations are generated by Phase 4 engines.
- Added explicit state/snapshot APIs to support live dashboards and auditable decision pipelines.
