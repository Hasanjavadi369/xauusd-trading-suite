# راهنمای دیپلوی — داشبورد وب با لینک عمومی (از طریق گیت‌هاب)

با این روش، وقتی هرکسی (حتی از گوشی) لینک را باز کند، داشبورد **به‌صورت زنده روی
سرور اجرا می‌شود** — بدون نیاز به نصب پایتون یا هیچ‌چیز دیگری روی دستگاه کاربر.

از **Streamlit Community Cloud** استفاده می‌کنیم: رایگان، مستقیم از گیت‌هاب دیپلوی
می‌شود، و با هر `git push` خودکار به‌روزرسانی می‌شود.

## قدم ۱: مطمئن شوید پروژه روی گیت‌هاب است

اگر هنوز انجام نداده‌اید، به `docs/INSTALL.md` یا راهنمای قبلی مراجعه کنید:

```bash
git remote add origin https://github.com/<username>/xauusd-trading-suite.git
git branch -M main
git push -u origin main
```

فایل کلیدی برای این مرحله از قبل در ریشه‌ی پروژه ساخته شده: **`streamlit_app.py`**

## قدم ۲: ساخت حساب Streamlit Community Cloud

1. به [share.streamlit.io](https://share.streamlit.io) بروید
2. با اکانت گیت‌هاب خودتان وارد شوید (Sign in with GitHub)
3. اجازه دسترسی به ریپازیتوری‌های گیت‌هاب را تأیید کنید

## قدم ۳: دیپلوی اپ

1. روی **New app** بزنید
2. تنظیمات:
   - **Repository**: `<username>/xauusd-trading-suite`
   - **Branch**: `main`
   - **Main file path**: `streamlit_app.py`
3. روی **Deploy** بزنید

بعد از حدود ۱ تا ۳ دقیقه، یک لینک عمومی به این شکل دریافت می‌کنید:

```
https://xauusd-trading-suite-<random>.streamlit.app
```

همین لینک را با هر کسی (روی گوشی، لپ‌تاپ، هرجا) به اشتراک بگذارید — با باز کردنش،
داشبورد بالا می‌آید و اجرا می‌شود.

## قدم ۴: به‌روزرسانی خودکار

از این به بعد، هر بار که تغییری را `git push` کنید، Streamlit Cloud خودش اپ را
دوباره می‌سازد و لینک همیشه آخرین نسخه را نشان می‌دهد — نیازی به کار دستی نیست.

## چه چیزی در این داشبورد کار می‌کند؟

| بخش | روی داشبورد ابری |
|---|---|
| آپلود CSV و تحلیل | ✅ کار می‌کند |
| چارت تعاملی با نواحی SMC | ✅ کار می‌کند |
| نمایش سیگنال فعلی (Entry/SL/TP) | ✅ کار می‌کند |
| بک‌تست + معیارهای عملکرد | ✅ کار می‌کند |
| تنظیم پارامترهای ریسک/SMC از UI | ✅ کار می‌کند |
| اتصال زنده به MT5 و ارسال سفارش | ❌ کار نمی‌کند (MT5 فقط ویندوز است؛ سرورهای ابری لینوکسی‌اند) |

برای اتصال زنده به MT5، باید نرم‌افزار را روی یک **VPS ویندوزی** خودتان اجرا کنید
(به بخش «اتصال زنده» در `docs/USAGE.md` مراجعه کنید).

## اجرای محلی همین داشبورد (اختیاری، برای تست قبل از push)

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

مرورگر به‌صورت خودکار روی `http://localhost:8501` باز می‌شود.

## محدودیت‌های پلن رایگان Streamlit Cloud

- منابع محدود (CPU/RAM کم) — برای فایل‌های CSV خیلی بزرگ (چند صد هزار کندل) ممکن است کند شود
- اگر اپ چند روز بدون بازدید بماند، «به خواب می‌رود» و اولین باز شدن چند ثانیه طول می‌کشد (Cold Start) — طبیعی است
- ریپازیتوری باید Public باشد (یا با پلن پولی، Private هم قابل دیپلوی است)
