Overview

XAUUSD Trading Suite is a professional Python-based platform designed for analyzing, backtesting, and managing Gold (XAUUSD) trading systems.

The goal of this project is to develop an intelligent trading environment that combines market data processing, algorithmic analysis, and artificial intelligence techniques.

The system is designed to work with MetaTrader 5 and provide a complete framework for future automated trading solutions.

Installation

Clone repository:

git clone https://github.com/Hasanjavadi369/xauusd-trading-suite.git

Enter project folder:

cd xauusd-trading-suite

Create virtual environment:

python -m venv .venv

Install dependencies:

pip install -r requirements.txt

Run project:

python main.py

---

Requirements

- Python 3.10+
- MetaTrader 5 Terminal
- Windows environment for MT5 integration
- Trading account connection
