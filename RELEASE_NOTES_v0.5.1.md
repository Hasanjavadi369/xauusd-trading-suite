# v0.5.1 — Dashboard & Final Trade Flow

## Changes
- Professional multi-page dashboard.
- Home page is chart-only.
- Dedicated pages for Signals, Demo Trading, Automatic Trading, Risk, AI, Backtest and Settings.
- Demo account execution is now explicitly stateful and isolated.
- Automatic demo trading requires a valid final BUY/SELL signal.
- Entry/SL/TP are generated only after final signal validation.
- BUY/SELL TP/SL geometry is validated before execution.
- No synthetic market prices are generated by the dashboard.
- Real OHLCV CSV upload supported for the UI.
